# Command Reference

| Command | Purpose | Example |
| ------- | ------- | ------- |
| `join` | Join list items into text | `join words in tokens with " " as sentence` |
| `replace` | Replace text patterns | `replace "cat" with "dog" in my_text as new_text` |
| `clean` | Remove punctuation and extra whitespace | `clean my_text as cleaned` |
| `lowercase` | Convert text or list items to lowercase | `lowercase my_text as lower_text` |
| `uppercase` | Convert text or list items to uppercase | `uppercase my_text as upper_text` |
| `stem` | Stem words in text or lists | `stem my_text as stems` |
